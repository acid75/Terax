# Logos

Archivos de marca de Terax. Todos son SVG de una sola tinta por elemento; `<img>` no hereda color, así que cada archivo trae sus colores fijos:

| Archivo | Tintas | Dónde |
| --- | --- | --- |
| `terax-wordmark.svg` | flecha `mint` #9be9dd, texto `text` #f3f6fa | Cabecera sobre `bg` / `glow` |
| `terax-wordmark-mono-light.svg` | `text` #f3f6fa | Fondos oscuros ajenos |
| `terax-wordmark-mono-dark.svg` | `bg` #0b1016 | Fondos claros |
| `terax-icon.svg`, `terax-icon-512.png`, `terax-icon-1024.png` | fondo `mint`, flecha y ondas `on-mint` #082a22 | Ícono de app (≥32px) |
| `terax-icon-small.svg` | fondo `mint`, flecha `on-mint` | 24px o menos |
| `terax-icon-dark.svg` | fondo `surface` #141d27, flecha y ondas `mint` | Fondos claros |
| `terax-symbol.svg` | `mint` | Notificaciones, efecto de escritorio |
