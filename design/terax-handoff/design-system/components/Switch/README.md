# Switch

Interruptor de ajustes: encendido en menta con pulgar oscuro; apagado con borde.

## Uso
- Siempre al final de una fila con título (`body`) y subtítulo (`caption`) que explica el efecto.
- Encendido: pista `mint`, pulgar `on-mint` grande. Apagado: borde y pulgar pequeño `control-off`. El tamaño y la posición del pulgar distinguen el estado, no solo el color.

## Lo que aporta quien la usa
Título, subtítulo, estado (`aria-checked`) y `aria-label`.
