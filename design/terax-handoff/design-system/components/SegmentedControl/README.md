# SegmentedControl

Selector Fotos / Documentos a ancho completo; la opción activa se rellena de `accent`.

## Uso
- Dos opciones con icono + texto en `label`. Activa: fondo `accent`, texto `on-accent`. Inactiva: transparente con texto `text`; borde `outline`.
- Windows: alto `size-segment`, esquinas `radius-md`. Android: ≈40dp, forma de píldora (`radius-full`).
- Cambia el contenido de la biblioteca y el placeholder del buscador («Buscar fotos» / «Buscar archivos»).

## Lo que aporta quien la usa
Las opciones y cuál está activa (`aria-selected`).
