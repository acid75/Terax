# EmptyState

Estado vacío o de espera: icono o ilustración, titular, explicación breve y una acción.

## Uso
- Centrado en el área de contenido. Icono `mint` de 48px o ilustración de líneas `illustration-line`.
- Titular: `headline` dentro de la biblioteca (Android) o `display` en una pantalla completa (Windows). Explicación en `body-lg` / `text-muted`, una o dos frases que dicen qué hacer.
- Como máximo un botón principal con la acción que resuelve el estado.

## Lo que aporta quien la usa
Icono o ilustración, titular, explicación y acción. Úsalo también para errores y permisos («Sin acceso a fotos», «Búsqueda sin resultados»), siempre con una acción si existe.
