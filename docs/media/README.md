# Medios públicos

- `android-library.png`, `android-preview.png`, `windows-receiver.png`: capturas del renderer Flutter de Terax con datos de demostración. Generadas mediante `TERAX_PUBLIC_MEDIA=1 flutter test test/public_media_test.dart`; fondos de ejemplo propios en `test/fixtures/public_media/`. No incluyen usuarios, fotos privadas ni códigos de vinculación reales.
- `terax-preview.gif` y `video-poster.jpg`: vista previa del video promocional aportado para la publicación.
- El video completo `terax-promo.mp4` se distribuye como archivo del release v0.5.4, para no almacenar el MP4 de 28 MB en el historial del código.
