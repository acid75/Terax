# Fuentes de Terax

Fuentes locales para Flutter; no hay descarga de fuentes durante el uso de la app.

- Figtree: archivo variable oficial de Google Fonts (`ofl/figtree/Figtree[wght].ttf`), copiado como `Figtree-VariableFont_wght.ttf`.
- Geist Mono: archivo variable oficial de Google Fonts (`ofl/geistmono/GeistMono[wght].ttf`). Las instancias TTF Regular (400) y Medium (500) se generaron con fontTools.varLib.instancer.
- Licencias OFL oficiales junto a los TTF; ambas están registradas en el catálogo de licencias de Flutter.

Fuentes originales y licencias: https://github.com/google/fonts/tree/main/ofl/figtree y https://github.com/google/fonts/tree/main/ofl/geistmono

Los WOFF2 del handoff se conservan en design/terax-handoff/design-system/fonts y no se usan como fuentes Flutter.
